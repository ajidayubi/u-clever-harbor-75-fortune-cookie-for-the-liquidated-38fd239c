A single fortune cookie message, at most 20 words of plain text, for a crypto trader who has just been liquidated. It has to sound like a real fortune and land as a joke on the loss.

Our fortune: "The stars predict great wealth in your future. They did not say whose wallet it would be in." The program writes that one line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
